A single-sentence pitch for a friend who has never coded, convincing them to let an AI agent on make.fun build their first app idea. The pitch's angle: the idea has been living rent-free in their head for months — it is time to stop describing it to anyone who listens and start holding the first real version in their hands.

Run it with:

```sh
python3 main.py
```

It validates the pitch (one sentence, at most 240 characters) and writes it to `/output/entry.txt`.
